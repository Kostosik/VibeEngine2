# Диагностика и восстановление

Это руководство описывает первые действия при типичных проблемах
с созданием, сборкой и запуском игрового проекта VibeEngine2.

## 1. Ошибка сборки игрового проекта

1. Открой консоль редактора и найди сообщения компилятора.
2. Найди первую конкретную ошибку, например `error CS1026`,
   и проверь указанные файл и строку.
3. Исправь исходный код и повторно запусти игру.
4. Если сборка снова завершилась ошибкой, проверь новые сообщения
   компилятора, а не только код завершения процесса.

Неудачная сборка сама по себе не означает, что игровой проект повреждён.
После исправления исходного кода сборку и запуск можно повторить.

## 2. Аварийное завершение игры

1. Проверь последние сообщения игрового процесса в консоли редактора.
2. Если выведено исключение, изучи его тип, сообщение и стек вызовов.
3. Проверь указанный участок кода и данные, с которыми работала игра.
4. После устранения причины запусти игру повторно.

Ненулевой код завершения означает, что процесс завершился с ошибкой.
Он не заменяет исходное сообщение об исключении и сам по себе
не объясняет причину сбоя.

Завершение игрового процесса не должно требовать перезапуска редактора.
Если сессия осталась активной после завершения процесса, проверь её
состояние и корректность остановки.

## 3. Не удаётся открыть игровой проект

Редактор открывает файл манифеста `.vibeproject`.

Проверь следующее:

- выбран правильный файл `.vibeproject`;
- файл проекта, указанный в `startupProject`, существует
  и имеет расширение `.csproj`;
- путь `startupProject` задан относительно каталога проекта;
- если указана стартовая сцена `startupScene`, её путь задан
  относительно каталога проекта и указывает на файл с расширением `.world`;
- если стартовая сцена не открывается, проверь, что соответствующий
  файл действительно существует и не был перемещён.

Исправь путь или восстанови отсутствующий файл, после чего
повтори открытие проекта.

## 4. Не удаётся создать игровой проект

Для создания проекта необходимы сборки Engine Runtime.

В установленном редакторе штатное расположение Runtime:

`EngineRuntime/win-x64`

При разработке из репозитория движка используется каталог:

`artifacts/engine-runtime/win-x64`

Если готовой поставки Runtime нет, редактор может попытаться
собрать её из исходников движка.

При ошибке создания проекта:

1. Прочитай полное сообщение об ошибке.
2. Проверь наличие необходимых сборок Runtime.
3. Если Runtime собирается из исходников, проверь наличие
   полного репозитория VibeEngine2 и установленного .NET 8 SDK.
4. Если сборка завершилась ошибкой, сначала устрани её причину,
   указанную в выводе сборки, а затем повтори создание проекта.

Если задана переменная окружения `VIBEENGINE_RUNTIME_DIR`,
проверь, что она указывает на каталог с корректной поставкой Runtime.

## 5. Что приложить к сообщению об ошибке

Чтобы упростить диагностику, укажи:

- действие, после которого возникла проблема;
- полный текст ошибки из консоли;
- стек вызовов, если он доступен;
- шаги, позволяющие повторить проблему;
- сведения о среде выполнения, если ошибка связана со сборкой
  или зависимостями.

Не ограничивай описание сообщением «игра не запускается»:
важно сохранить конкретную диагностическую информацию.
